DDD & architecture terms

TermMeaningSee
AggregateA cluster of entities and value objects treated as one unit for data changes, with one root entity that enforces its invariants.Tactical
Aggregate rootThe single entity through which an aggregate is accessed and modified.Tactical
Anemic domain modelClasses with data but no behaviour; the rules live in services. An anti-pattern when the domain is complex.Fundamentals
Anti-corruption layer (ACL)A translation layer that protects one context's model from another's.Strategic
Application serviceOrchestrates a use case: transaction, load, call domain, save, publish. No business rules.Application layer
Bounded contextA boundary within which a model and its language are consistent and unambiguous.Strategic
CommandAn immutable request to change state, named in the imperative (PlaceOrder).Application layer
Context mapA diagram of bounded contexts and the relationships between them.Strategic
Core / supporting / generic subdomainA classification of business areas by differentiation and complexity.Strategic
CQRSCommand Query Responsibility Segregation: separate models for writes and reads.Architecture
Dirty checkingHibernate compares managed entities to their loaded snapshot and issues UPDATEs at flush or commit.Persistence
Domain eventAn immutable record of something that happened in the domain, named in the past tense.Events
Domain serviceStateless domain logic that doesn't fit one entity.Tactical
EntityAn object defined by a continuous identity rather than its attributes.Tactical
Event StormingA collaborative workshop technique for exploring a domain with sticky notes.Strategic
Eventual consistencyDifferent parts of the system become consistent after a delay, instead of atomically.Events
FactoryEncapsulates the creation of complex objects or aggregates.Tactical
Hexagonal architecturePorts & adapters: the core defines interfaces, and the outside world plugs in.Architecture
Integration eventA stable, primitive-typed event shared between bounded contexts or services.Events
InvariantA business rule that must always be true for an aggregate.Tactical
Modular monolithOne deployable made of modules with enforced boundaries.Architecture
Optimistic lockingDetects concurrent updates through a version column instead of holding locks.Persistence
OutboxStore outgoing events in the same transaction as the state change, and relay them later.Events
Port / adapterA port is an interface owned by the core; an adapter is a technology-specific implementation.Architecture
ProblemDetailRFC 9457 standard JSON format for HTTP API errors.REST API
Published languageA documented shared format for inter-context communication.Strategic
Read model / viewA data structure shaped for a query or screen, with no behaviour.Application layer
RepositoryCollection-like access to aggregates that hides persistence.Tactical
Saga / process managerCoordinates a multi-step process across aggregates or services with compensating actions.Events
Shared kernelA small model subset shared by contexts and changed only by agreement.Strategic
Ubiquitous languageThe shared vocabulary of the team and the domain experts, reflected in the code.Fundamentals
Value objectAn immutable object defined by its attributes, with no identity.Tactical

Catalog context

TermMeaningCode
ProductSomething we sell, identified by a SKUcatalog.domain.Product
SKUStock-keeping unit; format LETTERS-DIGITS, e.g. BOOK-0001Sku
Stock on handUnits physically available and not reserved. Never negative.Product.stockOnHand()
Receive stockGoods arrive from a supplier; stock increasesProduct.receiveStock()
ReserveSet aside stock for a placed orderProduct.reserve()
ReleaseReturn reserved stock after a cancellationProduct.release()
ActiveAvailable for sale; inactive products can't be reservedProduct.isActive()

Ordering context

TermMeaningCode
OrderA customer's request to buy productsordering.domain.Order
DraftAn order still being assembled; lines can changeOrderStatus.DRAFT
Order lineOne product on an order, with quantity and the price at the time it was addedOrderLine
PlaceThe customer commits to the order; stock is reserved; lines are frozenOrder.place()
ShipThe order leaves the warehouse; it can no longer be cancelledOrder.ship()
CancelAbandon a draft or placed order; placed orders release their stockOrder.cancel()
TotalSum of line totals in the order's single currency; always computed, never storedOrder.total()
Orderable productOrdering's view of a catalog product: name, price, and whether it can be ordered nowProductCatalog.OrderableProduct
